# Ressourcen

Dieses Verzeichnis enthält automatisch generierte GeoJSON-Dateien aus der Overpass API (OpenStreetMap).

Die Dateien werden von `fetch_data/fetch_overpass.py` erzeugt und nach Bundesland und Kategorie unter `geojson/` einsortiert.

**Wichtig:** Die Dateien sind generiert und sollten nicht manuell bearbeitet werden.
